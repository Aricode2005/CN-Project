RARP: "What is my IP?" shouted on the wire

RFC 903 · Reverse Address Resolution Protocol · Finlayson, Mann, Mogul, Theimer · June 1984

ARP asks "which MAC owns this IP?" RARP asks the opposite, "which IP belongs to my MAC?" It uses the same 28-byte packet with opcode 3/4 and its own EtherType 0x8035. It runs directly on Ethernet with no IP and no UDP, so its frames travel on the simulated LAN below, byte for byte. Click a workstation to boot it.

BOOTP: everything to boot, across routers

RFC 951 · Bootstrap Protocol · Croft & Gilmore · September 1985 · relay RFC 1542 · vendor extensions RFC 1497

BOOTP moves up to UDP (client port 68 to server port 67) and replies with far more than an address: the IP (yiaddr), the boot server (siaddr), the boot file to fetch with TFTP, and a mask, router, DNS server and host name in the vendor area. Its key improvement is the relay agent: a router that catches the broadcast, writes its own address into giaddr and forwards it to a server on another LAN. Every packet here is a real 300-byte BOOTP message over a real UDP socket.
