\section{Introduction}
\noindent Routers build their forwarding tables with a routing algorithm. Two families dominate inside an organisation, and a third connects organisations:
\begin{itemize}[leftmargin=2em]
    \item \textbf{Link state} (OSPF, RFC 2328): every router floods the state of its own links to all others, so every router holds the same map and computes shortest paths with \textbf{Dijkstra's algorithm}.
    \item \textbf{Distance vector} (RIP, RFC 2453): a router knows only its neighbours and tells them its current distance to every destination. Each router applies the \textbf{Bellman--Ford} equation
    \[ D_x(y) = \min_{v \in \text{neighbours}(x)} \{\, c(x,v) + D_v(y) \,\}. \]
    Good news spreads quickly, but bad news spreads slowly: after a failure, routers can keep using each other's stale distances and \textbf{count to infinity} (16 in RIP) while packets loop between them. \emph{Split horizon} and \emph{poison reverse} fix loops between two routers but not loops through three.
    \item \textbf{Path vector} (BGP-4, RFC 4271), used between autonomous systems (ASes): every advertisement carries the full \textbf{AS\_PATH}, and a router rejects any path that already contains its own AS. Loops therefore cannot form.
\end{itemize}

\subsection{What Was Built}
This module demonstrates all three families on small networks and puts every routing message on the wire, in pure Java 11 with no external libraries:
\begin{enumerate}[leftmargin=2em]
    \item \textbf{Dijkstra} step by step on the textbook's six-router network, recording $N'$, $D(v)$ and $p(v)$ after every step.
    \item \textbf{Synchronous Bellman--Ford} with RIP's infinity of 16, optional split horizon and poison reverse, on the six-router network (cold start), a three-router network (good and bad news), a line of three routers and a triangle with a stub.
    \item \textbf{OSPF} reacting to the same failure: new Router-LSAs with higher sequence numbers are flooded, then Dijkstra is rerun.
    \item \textbf{BGP} reacting to the same failure with AS\_PATH loop detection.
    \item \textbf{Real packets:} every distance vector is sent as a RIPv2 response over UDP 520, every LSA as an OSPF LS Update (with both checksums) carried in UDP 8900, and every BGP OPEN, UPDATE and KEEPALIVE over a real TCP session on port 179, between six loopback addresses 127.0.0.20--25. Wireshark decodes them.
    \item \textbf{A dashboard} on \texttt{http://localhost:8088} designed as a railway signal box, with one lever per experiment and a \textbf{Forward} control that advances one round at a time.
\end{enumerate}

\section{Dijkstra's Algorithm (Link State)}
Starting from the source, the algorithm repeatedly settles the unsettled router with the smallest known distance and then checks whether going through it shortens the path to each of its unsettled neighbours.

\begin{lstlisting}[language=Java, caption={The main loop of \texttt{sim/Dijkstra.java}.}]
dist[src] = 0; done[src] = true;
for (int v : t.neighbours(src)) { dist[v] = t.cost[src][v]; prev[v] = src; }   // step 0
for (int k = 1; k < n; k++) {
    int w = -1;                                                  // closest unsettled router
    for (int v = 0; v < n; v++) if (!done[v] && dist[v] < Topo.NONE && (w < 0 || dist[v] < dist[w])) w = v;
    if (w < 0) break;                                            // the rest is unreachable
    done[w] = true;                                              // add w to N'
    for (int v : t.neighbours(w)) {
        if (done[v]) continue;
        int alt = dist[w] + t.cost[w][v];
        if (alt < dist[v]) { dist[v] = alt; prev[v] = w; }        // a shorter path through w
    }
}
\end{lstlisting}

On the textbook network (links u--v 2, u--x 1, u--w 5, v--x 2, v--w 3, x--w 3, x--y 1, y--w 1, y--z 2, w--z 5) from source u, the recorded table is:

\section{Bellman--Ford (Distance Vector)}
In every exchange each router sends its whole distance vector to each neighbour as a RIPv2 response; then every router recomputes its table from the vectors it last heard. Split horizon omits the routes whose next hop is the neighbour being told; poison reverse sends them with metric $\infty$ instead.

\begin{lstlisting}[language=Java, caption={What router x tells neighbour v (\texttt{sim/DistanceVector.java}).}]
private List<Rip.Entry> advert(int x, int v, List<Integer> omitted, List<Integer> poisoned) {
    List<Rip.Entry> e = new ArrayList<>();
    for (int d = 0; d < n; d++) {
        if (d != x && next[x][d] == v && split) {                   // this route goes through v
            if (poison) { e.add(new Rip.Entry(d, inf)); poisoned.add(d); }   // poison reverse: say "infinity"
            else omitted.add(d);                                   // split horizon: say nothing
            continue;
        }
        e.add(new Rip.Entry(d, D[x][d]));
    }
    return e;
}
\end{lstlisting}

\textbf{Cold start.} On the six-router network, starting from direct links only, 16 table entries changed in the first exchange, 6 in the second and none in the third: converged in 3 exchanges with 60 RIP packets, and every distance equals Dijkstra's.

\subsection{Good News and Bad News}
Three routers x, y, z with links x--y 4, x--z 50, y--z 1; the table shows each router's distance to x and its next hop.
\begin{itemize}[leftmargin=2em]
    \item \textbf{x--y drops from 4 to 1}: converged in 2 exchanges.
    \item \textbf{x--y rises from 4 to 60}: y recomputes using z's old distance 5 (which goes through y itself) and chooses 6 via z. The two now point at each other, and their distances climb by 2 per exchange until z's count exceeds its direct link of 50.

\section{The Same Failure with OSPF and BGP}

\subsection{OSPF}
When C--D fails, C and D each originate a new Router-LSA listing only their working links, with the sequence number raised from \texttt{0x80000001} to \texttt{0x80000002}, and flood it. A router installs and forwards an LSA only if its sequence number is newer than the copy it holds; a duplicate is acknowledged and not forwarded, so flooding stops by itself. In the first flooding round 2 LS Updates were delivered and passed on; in the second, the duplicates were dropped. Every router then held the same LSDB and Dijkstra marked D unreachable: \textbf{2 rounds, 4 LS Updates, no loop at any time}. Every packet passed both the OSPF one's-complement checksum and the LSA Fletcher checksum.

\shot[0.85\textwidth]{10_ospf_fix.png}{OSPF floods the new LSAs and reruns Dijkstra: no counting.}

\subsection{BGP}
Four ASes in the same triangle-plus-stub shape: A = AS 100, B = AS 200, C = AS 300, and D = AS 400, which owns 10.4.0.0/16. A path is stored only if it does not already contain the receiving router's own AS.

\begin{lstlisting}[language=Java, caption={Importing an UPDATE with the AS\_PATH loop check (\texttt{sim/PathVector.java}).}]
if (u.path == null) {                                  // a withdrawal
    ribIn[v][x] = null; ribNote[v][x] = "withdrawn";
} else if (u.path.contains(t.as[v])) {                 // my own AS is already in the path
    ribIn[v][x] = null;
    ribNote[v][x] = "rejected: loop (AS " + t.as[v] + " already in " + u.path + ")";
} else {
    ribIn[v][x] = u.path;                              // store it; best path chosen afterwards
}
\end{lstlisting}

\section{Conclusion}
\begin{enumerate}[leftmargin=2em]
    \item \textbf{Dijkstra and Bellman--Ford reach the same answer by different routes.} The cold-start distance vectors converged to exactly Dijkstra's distances, but distance vector needs only neighbours' vectors while link state needs the whole map.
    \item \textbf{Distance vector is fragile after failures.} Bad news took 47 exchanges on three routers, and two routers counted to infinity in 15. Split horizon and poison reverse helped only when the loop involved two routers; a three-router loop still counted to 16.
    \item \textbf{More information removes the loops.} OSPF floods the changed link and recomputes from a complete map (2 rounds), and BGP's AS\_PATH lets each router recognise a path through itself (3 rounds). Neither counted to infinity.
\end{enumerate}
